# Photos

Two folders — drop desktop photos into `web/`, mobile photos into `phone/`. Use the SAME filenames in both:

| Filename | Where it appears |
|---|---|
| `hero-1.jpg` … `hero-6.jpg` | Home slideshow (slides in from the right, 5s per photo) |
| `invite.jpg` | Wide strip under "You are invited…" |
| `church-old.png` | Historic sepia venue photo above "Church Ceremony" |
| `church-steeple.png` | Cream steeple sketch left of Church Ceremony |
| `civil-sketch.png` | Faint aisle sketch behind Civil Ceremony |
| `dinner.jpg` | Background of the Dinner section |
| `with-love.jpg` | Background behind the closing "M & G" |

The site switches to the `phone/` versions below 640px screen width.

After replacing files, hard-refresh the browser (Ctrl+F5) to bypass cache.
